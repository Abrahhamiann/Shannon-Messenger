# Visual foundation
Reference: Shannon Private Messenger UI Showcase (1).png supplied by the user.
All visible screens were considered: welcome/identity, chat list/conversation,
attachment menu, call/call history, settings/privacy, and bottom navigation.

M1 adopts the reference's near-black background (#050B10), graphite surface
(#0B1218), blue actions (#3B82F6), lighter blue highlights (#60A5FA),
off-white text (#F3F6FA), muted text (#98A7B9), and subtle borders (#263341).
Light mode uses #F8FAFC / white with #2563EB accents and dark text.
Android uses the platform Roboto typography. Headings 24, secondary text compact,
48dp primary actions, rounded 12–16dp corners, and no decorative animation.

M1 screens: welcome, empty chats/calls/contacts, settings, and real connection
diagnostics with loading/error/retry/success states. Theme is session-only.
The S letter is a temporary typographic mark, not the final reference ribbon logo.
Exact logo artwork and full screenshot-matched screens belong to later design
work. Do not introduce fake chats or unimplemented security claims.
