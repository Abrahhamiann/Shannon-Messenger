# Product requirements
Shannon is an Android-first private messenger with future iOS and desktop support.
The supplied master specification is the long-term product scope. The current
user request defines M1: application, themes, navigation, HTTP server, PostgreSQL,
migrations, health connectivity, automated tests, and Windows run instructions.

Future requirements include cryptographic identity without phone/email,
QR/invite-only contacts, reviewed end-to-end encryption, multi-device support,
encrypted backups, and calls. No public presence, typing indicators, or read
receipts. Nothing in M1 implements these security or messaging features.
